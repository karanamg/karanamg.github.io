What happens when you press Run

Integrasi Connect · AI Data Hub: from a customer's system to RAG-ready AI knowledge
Integrasi ConnectAn Aras Integrasi solution · Powered by Boomi
In one sentence: Boomi goes to the customer's system, pulls the latest records, reshapes them the way this customer asked, removes personal data, and cuts them into pieces the AI can search, then hands them to the AI platform. It takes a few seconds, and no code is written per customer: it is all configuration.

The 9 steps on screen

  1. 1
    Integrasi Connect
    Request leaves the portal
    One request with everything Boomi needs: the customer and its data classification, the source system and settings, the customer's mapping and privacy rules.
    Each customer's setup is stored as data, not code. A new customer is a new configuration, not a new project.
  2. 2
    Boomi API Service
    Boomi receives the request
    Arrives at a secure Boomi API (/ingest), which any Aras Integrasi product can call.
    Built once, reused across products: these are the composable APIs.
  3. 3
    Boomi · Ingest pipeline
    Read the request
    Boomi keeps the customer, source and rules for the rest of the run.
    One pipeline serves every customer.
  4. 4
    Boomi · Route by source system
    Pick the right connector
    SAP S/4HANA (live sandbox) · Salesforce (simulated in the demo) · File / CSV · data.gov.my (live).
    Add a system once, as one new path, and every customer can use it.
  5. 5
    Boomi · Source connector
    Fetch the records
    Boomi connects to the source and reads the latest data. Tab 1 · Data fetched from source
    Raw data exactly as it arrived, including personal details, shown only in the admin portal.
  6. 6
    Boomi · AI data prep
    Apply the customer's mapping
    Each record becomes an AI document: ID and title from templates, content fields, metadata labels; unneeded fields are left out. Tab 2 · Mapping applied
    Each customer decides what its AI should know. A change in the mapping studio is used on the next run, with no developer and no redeploy.
  7. 7
    Boomi · AI data prep
    Mask personal data (PDPA)
    Fields marked sensitive become [REDACTED]; Boomi also finds [MYKAD], [PHONE] and [EMAIL] inside free text.
    Happens inside Boomi, before data leaves the integration layer. The AI platform never receives personal data, and the runtime can run in Malaysia or on-premise.
  8. 8
    Boomi · AI data prep
    Chunk for RAG
    Documents are cut into overlapping pieces of about 500 characters, each labelled with customer, source, classification and record ID.
    "RAG-ready": the AI finds the right passage and can cite where it came from.
  9. 9
    Aras AI platform
    Embed and index
    The chunks go into this customer's own search index, and "AI knowledge" answers questions with citations. Tab 3 · Sent to the AI platform
    Not Boomi. In production: the embedding model and vector database on MTAI GPUs. In the demo, the portal stands in.
